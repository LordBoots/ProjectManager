## Landing Page:
This is the first page the user sees when they open the application.
It has Four main sections: 
- Top Bar:
    - Title: "Project Manager" 
    - Tabs: "Home", "Mind Map", "Kanban", "Suggestions", "Settings"

Right Sidebar:
This will hold Suggestion Cards that the user can click to view the suggestion.
These cards are always visible and clicking them takes the user to the part of the wiki, mind map or kanban board that the suggestion is related to while opening the suggestion in the sidebar.
When a user hovers over sentances, objects, images, kanban cards, mind map cards, etc. relevant suggestions will automatically highlight in the sidebar.

Top Content Area:
This will host the cards the user can click to navigate to the Kanban Board and Mind Map.

Bottom Content Area:
This area will be used to host cards for all of the wiki pages.
The user can click on a card to view the wiki page.
Each card has a name, description, and an icon.
